# 网易云音乐 · 沉浸式概念落地页

[在线查看 GitHub Pages 网站](https://yemin11238.github.io/netease-cloud-music-landing/)

非官方概念作品，仅针对 PC 桌面展示。这个公开仓库主要用于 GitHub Pages 网页展示；公开可查看不等于授予复制、改编或再分发许可。

页面由 14 个章节组成。首屏全屏视觉随滚动收束为圆形，后续串联唱片、歌单、音乐人、现场、黑胶与日常时刻。交互包含鼠标视差、卡片入场、唱片筛选、海报弹窗、黑胶旋转、时段预览、章节导航及“暂停动效”。目前是图片与实时动效版本，尚未接入分段视频。

## 本地预览

无需安装依赖。在仓库目录运行：

```sh
python3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。主页是 `index.html`，全部资源使用相对路径，可直接由 GitHub Pages 托管。
